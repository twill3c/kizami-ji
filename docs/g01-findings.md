# G-01 —— δ は「危うさ」ではなかった

実施 2026-08-30(loop_004)。**閾値は SPEC §4 に測る前から書いてあり、一つも動かしていない。**

## 何を確かめようとしたか

企画の目玉は「δ が小さい箇所は、解析器が薄氷を踏んでいる」だった。
これを IPADIC の分割で採点したら循環する(辞書が自分の自信を自分で採点することになる)。
そこで**青空文庫のルビ**を外部の物差しに使った ——
ルビが振られた漢字列は、人間がそこをひとまとまりと見た証拠であり、辞書とは無関係に存在する。

- **母集団**: 最小経路が引いた内部境界(ルビを含む文の中)
- **ラベル**: その境界が 2 文字以上のルビの括りの内部に落ちているか(= 境界違反)
- **予測子**: δ_local(その境界)
- **閾値**: 下位四分位と上位四分位で違反率の比が **1.5 倍以上**、Spearman が負で α = 0.05

## 結果 —— 落ちた

青空文庫 1,500 作 / 12,157 文 / **400,456 境界**(乱数種 20260830・シャッフル 2,000 回)。

| | 値 | 判定 |
|---|---|---|
| 違反率(全体) | 1.050% | — |
| Q1(δ 小)の違反率 | 1.419% | — |
| Q4(δ 大)の違反率 | 1.190% | — |
| **Q1 / Q4 の比** | **1.193** | **閾値 1.5 に届かない** |
| Spearman ρ | −0.0295 | 符号は合っているがほぼゼロ |
| δ シャッフル対照の経験 p | 0.000 | 向きは偶然ではない |

**向きは正しく、大きさが足りない。** これがいちばん厄介な落ち方で、
「有意だから効いている」と言いたくなる。p が 0 なのは標本が 40 万あるからで、
効果の大きさとは別の話である。40 万件あれば 1.19 倍でも「偶然ではない」と言えてしまう。

## 交絡を測ったら、効果は消えた

δ が小さい境界は**漢字の連続の内部に多い**。漢字熟語は辞書に載っているので、跨ぐ候補が出るからだ。
そしてルビもまた漢字に付く。つまり「δ が小さいほどルビを跨ぐ」は、
**両方が漢字らしさの関数であるだけ**でも成立しうる(猫アトラス HC-025 と同型)。

| | Q1(δ 小) | Q4(δ 大) |
|---|---|---|
| 境界が漢字連続の内部にある率 | **22.4%** | **11.3%** |

二倍の開きがある。そこで**漢字連続の内部に限った部分集団**(51,941 境界)で同じ検定をした。

| | 値 |
|---|---|
| Q1 の違反率 | 7.239% |
| Q4 の違反率 | 8.833% |
| Q1 / Q4 の比 | **0.820** |
| Spearman ρ | **+0.0268** |

**効果が反転した。** 漢字らしさを揃えると、δ が大きい境界のほうがむしろルビを跨ぐ。
全体で見えた 1.193 倍は、漢字らしさの影だったと考えるのが自然である。

## なぜそうなるか

境界は「解析器が切ることを選んだ場所」にしか存在しない。
跨ぐ語が辞書にあって、しかも安ければ、そもそも境界は引かれない。だから:

- **δ が小さい境界** = 跨ぐ語はあるが僅差で負けた場所
- **δ = ∞ の境界** = 跨ぐ語が辞書に一つも無い場所(全境界の **83.0%**)

そしてルビは、読みにくい語・見慣れない語に振られる —— つまり**辞書に載っていない語**に振られる。
ルビの括りを跨ぐ境界の多くは、僅差の判断ではなく、**語彙不足による強制的な分割**だった。

実例(いずれも δ = ∞、辞書に跨ぐ語が無い):

```
ルビ基底「両世界」  → 両 | 世界
ルビ基底「青醒」    → 青 | 醒
ルビ基底「至大艱難」→ 至大 | 艱難
```

## 途中で物差しを取り替えた —— その記録

最初の測定では、ルビの基底を**自動推定**(直前の同一文字クラスの連続)で取っていた。
これは青空文庫の記法どおりだが、実例を見て壊れていると分かった。

```
ルビ基底「処躊躇」  → 処 | 躊躇
ルビ基底「多年斯」  → 多年 | 斯
```

「処躊躇」も「多年斯」も語ではない。ルビは 躊躇 / 斯 にだけ付いていて、
自動推定が直前の漢字を巻き込んでいる。これを「人間が一語と見た証拠」として使っていた。
**落ちたゲートが計器の故障だった**ケース(kototoi-do HC-001 と同型)。

そこで **`｜` で明示的に括られた基底だけ**を人間の区切りとみなす形に替えた
(`蒼然《そうぜん》` `甚五郎《じんごろう》` `浮世小路《うきよこうじ》` —— どれも語になっている)。
上の結果はすべてこの物差しによるもの。

さらに測定中、`｜` の分岐が注記を素通りさせている欠陥も見つかった ——
`※［＃「罘」の「不」に代えて…］` が丸ごと基底に入り、本文へ注記の生テキストが混ざっていた
(120 作で 47 件)。直してから両方を測り直したのが上の数字である。
最初はこれを「基底が長すぎないこと」で捕まえようとして長さの上限を**観測せずに**書いたが、
実データには 23 文字の正当な基底があった ——
「早く歸つてね、私の好いお友達大すきなジャネット」にフランス語の読みを振った例である。
長さは注記混入の代理でしかないので、**述語**(基底に ［ ＃ ］ ※ を含まないこと)に書き換えた。

**結果を見てから物差しを替えた**ことは隠さない。替えた理由は結果と独立で
(「処躊躇」が語でないことは数字を見なくても分かる)、替えたあと一度だけ測って、それでも落ちた。

**そして、どちらの物差しでも結論は同じだった。** 自動推定版も同じ規模で測り直してある
(`data/g01_auto.json`)。

| | ｜ で明示された括り | 自動推定の括り |
|---|---|---|
| 境界 | 400,456 | 344,000 |
| Q1 / Q4 の比 | 1.193 | **1.057** |
| Spearman ρ | −0.0295 | **+0.0022** |
| 経験 p | 0.000 | 0.073 |
| 漢字連続に限った比 | 0.820 | **0.503** |
| 同 Spearman ρ | +0.0268 | **+0.148** |

自動推定版のほうが、むしろ反転がはっきりしている。**物差しを替えたことで結論が動いたわけではない。**

## 決めたこと

SPEC §4 の規定どおり、**F-07 と F-04 の「危うさ」という言い方を捨てる**。

- δ は出す。ただし **「解析器が迷った量」という内部量**としてのみ提示する
- 「δ が小さい ⇒ 間違いやすい」とは書かない。**測って、そうならなかった**
- 「危うい文」ページは **「僅差の文」** に改める。同点・僅差の実例は引き続き出す ——
  それらが**実在すること**は測れており、そこは主張として立つ
- 代わりに測れたことを出す: **全境界の 83.0% は δ = ∞**、すなわち
  跨ぐ語が辞書に一つも無い。**形態素解析の分割の大半は、迷った末の判断ではなく、
  語彙がそこにしか道を残していないという事実の反映**である

この最後の一つは、当初の目玉より地味だが、測って出てきたものである。
